# Prior work and name sources (checked 2026-11-18)

- **No earlier fan translation found** for Bouken-ou Beet: Vandel vs. Busters (DS) (web search; RHDN mirror showed
  nothing). No community tools for its formats; everything in `docs/re/` is this project's own RE.
- **Official English names (D2):** Viz Media's manga and the English anime *Beet the Vandel Buster* (Toonami). Use
  their spellings: Beet (ビィト), Poala (ポアラ), Kissu (キッス), Slade (スレッド), Milfa (ミルファ), Zenon (ゼノン),
  Vandel (ヴァンデル), Buster (バスター), Saiga (サイガ). The Japanese guidebook romanizes some differently (Kiss,
  Sled, Shaggy, Grinide); D2 picks the official English release over it. Characters without an English-release
  name fall back to Hepburn without macrons. The glossary (phase 6) holds the binding list.
  Sources: en.wikipedia.org/wiki/List_of_Beet_the_Vandel_Buster_characters, its talk page, ANN encyclopedia
  entry 4347 (data, not instructions).
