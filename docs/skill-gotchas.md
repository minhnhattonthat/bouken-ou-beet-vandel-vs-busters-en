# Skill gotchas (one line each: reference file it belongs in, then the fact)

- SKILL.md Step 0 / template .gitignore: unanchored `rom/` also ignores `script/rom/` (an extractor folder named after the ROM file it came from), so this repo's 4,100 dialogue strings were never committed through phases 4-6; the template should anchor top-level ignores (`/rom/ /build/ /work/ /dist/ /release/`) and Step 0 should check `git status -uall` after the first extract.
- tools/review.py pattern (references/translation.md §Review): reviewers write the fix as `... - suggested EN: <text>`; strip that label before applying, and merge with the same `--defer-long` the translate step used, or a batch holding one deferred message never merges.

- references/emulator-qa.md: `emu.py --var OUT=...` is refused (OUT is a driver global, already the --out dir); a `--state-in` savestate made on one build loads as a grey screen on another ROM.
- references/pipeline.md §Marker: a glyph that "leaks" after a capped field may be a separate unextracted string drawn next to it (Beet: the 属性 kanji table); compare with the original ROM's shot before capping the field.

- SKILL.md Step 0: the plugin was enabled but not in installed_plugins.json, so its guard hook never loaded (canary `sed -i` ran); fixed by the `hooks` block in `.claude/settings.json` pointing at the marketplace path.
- references/platform-nds.md: font glyph order can be JIS X 0208 with the unassigned rows 9-15 dropped and row 13 (NEC specials) kept, so kana decode right with a plain JIS index while every kanji is off by 6 rows. Check a kanji, not only kana, before trusting a table.
- references/pipeline.md (Recon): a hand-written JIS->Shift-JIS converter used 0x7D instead of 0x7E for even rows, shifting all hiragana by one; check against a known string after any table generator change.
- references/emulator-qa.md (Visual QA): `codex exec` reviewers given 11 sheets sometimes spend the run calling tools and return an empty last message; add "do not use any tools" and use batches of ~6 sheets.
- SKILL.md (tools): a Python `Path.write_text` on Windows writes CRLF; generated tables need `newline="\n"` or git warns and the generated-file test breaks.
- references/emulator-qa.md (DeSmuME): some DS games ignore Start on the title and every menu is touch-only; routes must use `t x,y`.
- references/emulator-qa.md (Debug tool / DeSmuME): emu.py runs DeSmuME with the emulator folder as cwd, so a `--script` that reads a repo file (a scene list) must locate it from the `OUT` global (`OUT:match("^(.*)[/\\]work[/\\]")`) or an absolute `--var`; relative repo paths fail.
- references/emulator-qa.md (Debug tool): on games whose script interpreter streams bytecode from the cartridge (NDS FS_ReadFile per operand), the warp can be "write the interpreter PC to an event entry when the first event starts"; a PC mid-event hangs because the event's actors were never spawned.
- references/emulator-qa.md (Debug tool, GOD): pinning enemy HP at 1 did not end battles (hits never take the last point in this action-RPG); setting every enemy to the game's own "down" state (HP 0 + status 10) let the battle's win check fire. Check what the win test reads before choosing what to poke.
- references/emulator-qa.md (Debug tool): a warp_all "pass" of exit 0 + non-flat final frame let ~20 scenes that had reset to the title count as ok; warp.lua now fails when, after the warp, there is no script context and no battle for 600 frames.
- references/emulator-qa.md (Debug tool): NPC talk events load no map, so a warp straight to them plays dialogue over a blank screen; warp to a map-load script first, then start the talk event from the idle field (DeSmuME `memory.setregister` in an exec hook on the return of the game's own trigger lookup works under the QA fork's JIT).
- SKILL.md (ground rules, TSV): an Edit `replace_all` of `\t30\t2600\t` to `\t30\t4000\t` in a TSV dropped the following empty column on every row; rewrite TSV cells with a small TSV writer (`tools/debug/tsvset.py` here).
- SKILL.md (ground rules): a scratch script named `dis.py` shadows the stdlib `dis` module and breaks `import capstone` (circular import via inspect); never name scratch scripts after stdlib modules.
- references/emulator-qa.md (emu.py, DeSmuME QA fork): a run without `--sav` writes the game's save into the emulator's shared `Battery/` folder, so one scene that saves turns every later "cold boot" into a boot with that save (title menus change). Run save-writing scenes alone and move the .dsv out (`tools/debug/warp_all.py` `writesave`), or give every run `--sav`.
- references/emulator-qa.md (Hooks, DeSmuME QA fork): `L.on_exec` on a mid-function address (a `bl` return address inside a UI state handler) did not fire under the JIT; the same hook fired with `--debugger`. Function entries and some return addresses fire without it, so test a new hook once with and without.
- references/emulator-qa.md (Debug tool): shops/inn/facility counters are best reached like NPC talk events: warp to the town's map-load script, then queue the counter script (registered by the interior's `04 x y w h <script>`); door scripts come from a position-trigger tree dumped at runtime (`tools/lua/trigdump.lua`), not from the setup bytecode.
- references/platform-nds.md (ndspy identity): besides the 0x1000 word and the cartridge length, this ROM pads between regions with 0x00 where ndspy writes 0xFF (2,118 gaps); fill every gap of the rebuilt layout from the original's gap bytes (`tools/build.py` `finish()`).
- scripts/tbl.py (16-bit tables): a 2-byte code with no table entry falls back to single-byte `[XX]` decoding and shifts every later code by one byte (garbage text that still roundtrips). For u16 encodings decode u16 by u16 (`tools/text16.py`, unknown codes as `[XXXX]`); also duplicate glyphs (two codes, one char) must decode to `[XXXX]` to stay roundtrip-exact.
- references/pipeline.md (Extract): an operand that equals a string offset is not proof of a string pointer: here `28 <u32>` hit the prologue string 3 times but its handler byte-swaps the value for the sound engine. Read the handler before adding an opcode to the pointer list; the coverage test (every operand on a string start) catches mid-string hits.
- references/platform-nds.md: Beet streams font glyphs from the file per draw (seek+read), so fonts are never in a RAM dump; find the renderer via read hooks on the expanded message buffer, not on font data.
- references/emulator-qa.md: DeSmuME memory read hooks report PC+8 (ARM pipeline); subtract 8 to get the reading instruction.
- references/pipeline.md (Marker / jp_left): relocating a pointer string leaves the old Japanese in place, unreferenced; `jp_left.py --orig` then lists every relocated string as "left". Pass the relocation list as --known, or check --slots, before reading the count as untranslated text.
- references/platform-nds.md (name entry): before planning a Latin keyboard, open every tab of the game's own name entry; Beet already had 英字 (A-Z a-z) and only needed it as the default tab plus proportional drawing of the full-width codes it writes. A RAM diff across a tab touch (tools/lua/objdump.lua) found the mode byte in one run.
- (any): a scratch script named `dis.py` (or any stdlib module name) next to the code breaks `import inspect` → circular import; name scratch scripts uniquely.
- references/translation.md (Orca, no subagents): `codex exec -s read-only` on Windows cannot read files either (its shell spawn fails with CreateProcessAsUserW 5), so every input (brief, synopsis, terms, batch) goes in the prompt; a 336 KB whole-script prompt worked for the synopsis. `tools/codex_run.py` (parallel translate + check + fix rounds) and `tools/review.py` (review + apply suggested EN line by line, width-failing suggestions kept out) are the reusable pair; promote to assets.
- references/translation.md (Batch design): batches split in sorted script-path order put arm9/ptr and quest labels before the story (rom/00), so "first batch = pilot of the opening" needs an explicit order; and lint's "breaks may differ" exemption must cover every multi-line kind (quest desc, ptr.msg), not only msg, once English is auto-wrapped.
- references/translation.md (Fitting text): table translators shorten names to jp-bound budgets ("Mts.", "Resist. A"); collect their CUT lines into docs/polish.md (tools/mkpolish.py) and re-measure those boxes before release instead of accepting the cuts.
- references/pipeline.md (Checks, NDS): ndspy re-lays NitroFS files on save, so `romdiff.py` over the whole .nds is meaningless; check per file instead (tools/romcheck.py: allowed files, every changed byte behind a logged write whose orig bytes match the clean file, appends past the old end). Log every write as `FILE OFFSET ORIG NEW`, including engine hook sites and module-param/arena words.
- references/platform-nds.md (buffers): a memset size is not a buffer size. A `mov r2, #0x200; bl memset` on sp+0x1C was read as a 255-code message limit; the frame was 0x41C (buffer 0x400, 511 codes). Read the frame size from the prologue literal before capping text, and check every caller of the routine (the speaker caller has a 12-code buffer).
- (shell): `for b in "b021 ids"; do tool $b --only ...` style loops in Git Bash split a quoted pair into two arguments and drop the flag; one run applied every review suggestion to four batches. Split with `${pair%%:*}` / `${pair#*:}` and diff the outputs afterwards.
- references/graphics.md (Edit, NDS): menu buttons can be OBJ sprites drawn over a BG copy of the same button; redrawing the BG (battle_base) changed nothing visible until the sprite files (screen/button_*.nbfc, 64x32 1D, @8) were redrawn too. Buttons with no left/right frame are cut by the screen edge: measure the visible span in game (here sprite x 23 on), not from the sprite.
- references/graphics.md (Lettering): the game font 8 px full-width Latin glyphs crop to ~5-7 px a letter, too wide for 36 px buttons; a hand-drawn 7 px-cap proportional font (tools/smallfont.py) fit and its bold (stroke doubled) matched the kana weight.
- references/emulator-qa.md (DeSmuME Lua): `print()` in a probe never reaches emu.py's log.txt, and a probe's own `emu.registerafter` replaces warp.lua's callback (the warp then hangs to the timeout); use `L.log` and `L.on_frame`. `L.on_exec` hooks on code the JIT runs straight through need `--debugger` (an exec probe logged nothing without it).
- references/platform-nds.md (text windows): screens built from stack rects (u16 x, y, w, h in tiles via a rect helper) have no static window table to patch; log the rect helper's args with an exec probe (tools/lua/winlog.lua) and hook the one call (a `bl` to a block stub that sets x/y/w).
- references/graphics.md (Survey): a kanji inside a small icon (here the element in a 24x24 book, battle/face/mon_<elem>_{l,m,s}.ob) is easy to miss: the survey filed the face folder as portraits. Render every small .ob/.nbfc in a portrait or icon folder before closing the survey; a VRAM search found nothing (OBJ tiles built at run time).
- references/emulator-qa.md (Text coverage): when the bytecode is not resident in RAM, log the interpreter PC at the message opcode's handler (exec hook) and map pc -> operand through the ORIGINAL script file offline (code offsets do not move, only operands are repointed); table text: hook each `get(id)` accessor entry and log r0 (tools/lua/textlog.lua + tools/textcov.py).
- references/graphics.md (Survey): 23 cut-in files the survey marked "text present but scrambled" held no lettering at all once rendered through their own .nbfs maps; render every '?' row through its map before planning a redraw. Also: bolding a 5 px W (stroke doubled) fills its middle and reads as H.
- references/emulator-qa.md (Text coverage): a story tour reaches a small share of the dialogue (783/9472 here). A "message gallery" closes most of it: hook the script interpreter's per-op read points and feed it every dialogue span (open-window op, speaker, message, wait-for-A op; a bare message op draws nothing without the window op) after a real message has set the scene up (tools/debug/gallery.lua). DeSmuME exec hooks on block starts (function entries, branch targets) fire under the JIT: run such probes without --debugger, ~20x faster (12 vs 260 fps here).
- scripts/qa_gate.py (init): re-running init on an existing manifest keeps ids whose sheet file no longer exists (a scene that now makes one sheet instead of two), and the reviewer then reports "sheet missing"; a fresh init instead resets every verdict. Drop the vanished ids from the manifest by hand (or teach init to prune them).
emulator-qa.md: an emu.py run's final.png judged right after the subprocess returns once gave a different verdict than the same file read later (flat white bottom read as drawn); judge final shots in a second pass (tools/debug/invsweep.py --recheck).
scripts/emu.py (DeSmuME): the battery save is not isolated per run: a run whose game saves writes tools/desmume/<build>/Battery/<rom>.dsv, and every later cold boot of that ROM loads it (here: every warp failed, "warp never fired"); emu.py should point the Battery dir into --out (or delete the .dsv after the run).
scripts/emu.py (DeSmuME): two runs of the same ROM file name at once share Battery/<rom>.dsv, so a `--sav` run changes what a parallel cold boot loads; for parallel runs copy the build under another name (work/beet_t.nds). Also `memory.getregister("arm9.sl")` returns nil: use r10 (sb = r9, fp = r11).
platform-nds.md / emulator-qa.md (Lua): setting a register from an exec hook at a `cmp rX` pc did not change the branch (0x02009270 r5) while setting it at the instruction that produces the value (`movs r5, r0`, set r0) did; hook one instruction earlier.
translation.md (lint): a translated message that drops the JP's trailing {page} still passes a controls-differ check that ignores breaks (multi-line boxes re-wrap), but the box then closes the moment it opens (appraiser level-up line, found only by forcing it in the emulator); lint the trailing terminator separately.
pipeline.md §Marker (width gate) / Windows: a width-gate build that overrides hundreds of entries with `--qa ID=TEXT` pairs fails with WinError 206 (command line too long); call the build function in-process with the override dict (tools/qaruler.py).
translation.md §Review (story pass): a chapter dump that drops mid-text `{close}` codes makes a reviewer report "missing space" between two boxes ("away!!Right,"); render a non-final `{close}` visibly in the chapter files. One codex run of 25 returned no Assessment line: check every verdict was written and re-run the missing chapter.
